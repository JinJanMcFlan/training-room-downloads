# Training Room

Rocket League practice tracking by JinJanMcFlan.

This repository is intended only for Windows installer downloads, installation instructions and release notes. It does not contain the private development workspace or server configuration.

[Read the illustrated Windows setup guide](START-HERE.md).

[Download the Windows installer](https://github.com/JinJanMcFlan/training-room-downloads/releases/tag/v1.0.13).

## Install

1. Open this repository's **Releases** page and choose version **1.0.13**.
2. Download **Training-Room-Setup-1.0.13.exe** from the release assets.
3. Run the installer and launch Training Room.
4. Sign in with Discord when prompted. Online features require the Training Room server to be available and your account to have access.

The installer includes the application payload. Your first download and installation do not require downloading that payload from the founder's computer. Account sign-in, saved online data, party functions and the current updater still connect to the configured Training Room server.

## Updates

Open **Settings → Updates** to view the running desktop version, check for an update and read the release history. Finish your session before installing an update.

Version 1.0.13 still obtains update manifests and update bundles from the Training Room server. Hosting this installer on GitHub does not automatically move ongoing update traffic to GitHub.
